## 구성

- `index.html` — 목차 (각 편 대표 사진과 한 줄 요약)
- `post1.html` ~ `post4.html` — 각 편 본문. 시맨틱 HTML(`article`, `h1`·`h2`, `p`, `figure`/`figcaption`)과 Open Graph, JSON-LD(BlogPosting) 메타데이터 포함
- `images/` — 1~3편 사진 6장, `images/post4/` — 4편 사진 6장 (촬영 메타데이터를 제거하고 웹용으로 축소)
- `robots.txt` — 검색·사용자 요청용 크롤러(OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot, Googlebot, Yeti 등) 허용, AI 학습용 수집기(GPTBot, ClaudeBot, anthropic-ai, CCBot, Google-Extended) 차단
- `sitemap.xml`
- `llms.txt`, `llms-full.txt` — LLM이 읽기 좋은 요약과 4편 전문

## 서술 원칙

문헌에서 직접 확인되는 사실, 가족 소장자료에 대한 판독, 후손의 구술·전승, 그리고 아직 밝혀지지 않은 조사 과제를 구분해 서술했습니다. 추가 사료와 전문적 현지조사 결과에 따라 내용을 보완합니다.
